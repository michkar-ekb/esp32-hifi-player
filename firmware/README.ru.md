# Прошивка ESP32-S3

[English](README.md) · **Русский**

> ⚠️ **У платы два разъёма USB-C, и у каждого своя работа.** Прошивка — через разъём **COM** (UART).
> Звук с компьютера — через разъём **USB**. **После прошивки переткните кабель в гнездо USB**, иначе
> компьютер звуковую карту не увидит.

`player_fw/` — плеер, версия 0.9: сетевой плеер и USB-ЦАП для компьютера. По сети он ничего не
декодирует: принимает PCM от [сервера](../server), держит до ~40 с звука CD (~12 с 24/96) в PSRAM в том
виде, как пришёл (16 или 24 бит), и выдаёт в I2S.

- Выводы I2S: **BCLK = GPIO1, LRCK = GPIO2, DATA = GPIO42**, MCLK не нужен.
- Плате ES9038Q2M нужны **32-битные отсчёты I2S**: с 16-битными слотами она выдаёт только шум.
  16- и 24-битный звук кладётся в старшие биты 32-битных отсчётов.
- Поток идёт по **4 TCP-соединениям**: окно TCP ядра 5,7 КБ ограничивает одно соединение
  ~5 Мбит/с — мало для DSD и 24/96 на обычном домашнем Wi-Fi.
- Сеть читается напрямую сокетами lwIP по 8 КБ: `WiFiClient` гонит всё через буфер 1,4 КБ, и на 4+ Мбит/с
  плеер из-за этого отставал. Скорость приёма передаётся серверу и видна в пульте (5–8 Мбит/с при хорошей связи).
- Три задачи: сетевой поток и опрос сервера на ядре 0, вывод I2S на ядре 1 с высоким приоритетом.
  Пауза и громкость срабатывают сразу; новый трек или перемотка сбрасывают буфер, и звук начинается,
  когда набралось 2 с (чтобы на слабой связи не заикалось сразу после переключения).

## USB-ЦАП (`usb_audio.cpp`)

Родной USB ESP32-S3 работает как **звуковая карта USB Audio Class 2**: драйвер не нужен ни в Windows 10/11,
ни в Linux, ни в macOS. 16 и 24 бит, 44,1 / 48 / 88,2 / 96 кГц — 24/96 это потолок USB Full Speed.

- Асинхронный режим с обратной связью: темп задаёт генератор I2S, компьютер шлёт чуть больше или
  чуть меньше, чтобы в буфере держалось ~25 мс.
- Компьютер начал играть, и в потоке есть звук → плеер переходит к компьютеру, сеть встаёт на паузу
  (сервер об этом узнаёт). ▶ в пульте возвращает плеер сети. 5 с тишины, закрытый поток или выдернутый
  кабель — USB отпускается. Ползунок громкости Windows работает (для лучшего звука держите его на 100 %).
- В обычном режиме Windows пересчитывает звук в формат устройства (по умолчанию 48 кГц). Чтобы шла
  родная частота файла, включите в программе-плеере вывод WASAPI (Exclusive).
- Это свой маленький драйвер UAC2 поверх TinyUSB: встроенный звуковой класс ядра собран без обратной
  связи. TinyUSB отводит приёмный FIFO под два пакета по 582 байта — больше, чем есть у S3, — поэтому
  драйвер размечает его сам, под один. USB-драйвер ядра 2.0.17 не умел принимать изохронный поток —
  поэтому ядро 3.
- `http://<плеер>/usb` — счётчики, настройка FIFO и последние управляющие запросы.

## Залить готовую прошивку

> **Прошивайте через разъём COM (UART).** Когда закончите — переткните кабель в разъём **USB**, чтобы
> слушать с компьютера.
>
> Полная прошивка кабелем **сбрасывает настройки Wi-Fi**: настройте плеер заново через «S3 Hi-Fi Setup»
> (см. ниже). Кабель нужен один раз — дальше обновления идут по Wi-Fi.

**Windows, проще всего:** скачайте `s3hifi-flash-windows.zip` из
[Releases](https://github.com/michkar-ekb/esp32-hifi-player/releases/latest), распакуйте, подключите плату
(разъём COM) и запустите `flash.bat`. Он покажет COM-порты и спросит номер (Enter, если порт один);
`esptool.exe` (официальная сборка Espressif) и прошивка лежат внутри.

**Любая система:** скачайте `s3hifi-player-esp32s3-n16r8.bin` из
[Releases](https://github.com/michkar-ekb/esp32-hifi-player/releases/latest): загрузчик, таблица разделов
и прошивка одним образом, пишется с адреса 0. Подключите девкит разъёмом COM и выполните:

```
esptool.py --chip esp32s3 write_flash 0x0 s3hifi-player-esp32s3-n16r8.bin
```

(`pip install esptool`.) Образ собран для ESP32-S3 N16R8 (16 МБ флеш, 8 МБ PSRAM octal).

## Обновление по Wi-Fi

Скачайте `s3hifi-player-ota.bin` из [Releases](https://github.com/michkar-ekb/esp32-hifi-player/releases/latest),
откройте страницу настроек плеера (в пульте ссылка «настройки плеера», или адрес плеера в роутере), выберите файл
в разделе **«Обновление прошивки»** и нажмите **«Обновить»**. Страница покажет ход загрузки, плеер перезапустится
секунд через 15, настройки сохранятся.

На той же странице можно задать пароль на обновление (необязательно; без него обновить может любой в домашней сети).
Забыли пароль — прошейте кабелем через `flash.bat`, настройки сбросятся.

Из консоли (`curl` уже есть в Windows 10/11, Linux и macOS):

```
curl -F "f=@s3hifi-player-ota.bin" "http://<адрес плеера>/update?pw=<пароль, если задан>"
```

Страница есть начиная с 0.9; 0.7 и 0.8 принимают обновление только через `curl`. У версий до 0.7 адреса
`/update` нет: один раз прошейте кабелем.

## Первый запуск

Настройки Wi-Fi в прошивку не зашиты. При первом запуске (или если сохранённой сети нет минуту) плеер
поднимает точку доступа **«S3 Hi-Fi Setup»**: подключите к ней телефон, страница настроек откроется сама
(или зайдите на `192.168.4.1`). Выберите свою сеть, введите пароль, сохраните. Сервер найдётся сам: плеер
шлёт `S3HIFI?` на UDP-порт 8097, сервер отвечает. Адрес сервера можно вписать и вручную (`хост` или
`хост:порт`) — например, сервер на VPS в интернете. Кнопка **BOOT**, зажатая на 5 секунд, стирает настройки.

Та же страница открывается по адресу плеера в домашней сети (в пульте — «настройки плеера»): там видно
сеть, сигнал, сервер и состояние USB-ЦАПа, и их можно поменять. Пустой пароль оставляет сохранённый.

## Сборка

Ядро Arduino для ESP32 **3.3.8**, настройки платы (режим USB: USB-OTG / TinyUSB):

```
arduino-cli compile --fqbn esp32:esp32:esp32s3:PSRAM=opi,FlashSize=16M,USBMode=default player_fw
```

Перед сборкой ничего править не нужно: Wi-Fi настраивается с телефона (см. выше).
